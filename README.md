# Микшер

Управление громкостью отдельных приложений на компьютере с телефона.

```
Телефон (приложение Android / страница /mixer/)  ⇄  сайт (server/mixer.php)  ⇄  программа на ПК (Mixer.exe)
```

Компьютер сам подключается к сайту, поэтому телефон работает из любой сети: ни портов, ни настроек роутера.

## Что где лежит

| Папка | Что это |
|---|---|
| `server/` | `mixer.php` (посредник) и `mixer/` (интерфейс: страница, PWA, внутри Android-приложения). Кладутся в корень сайта: `public_html/mixer.php`, `public_html/mixer/` |
| `windows/` | программа для ПК (трей, окно, автозапуск, обновление), тесты в `windows/tests/` |
| `android/` | приложение Android: окно с интерфейсом из `server/mixer/` + сканер QR |
| `.github/workflows/` | `tests.yml` — проверки на каждый коммит; `release.yml` — выпуск APK и EXE; `android.yml`, `windows.yml` — разовые сборки |

## Первый запуск

1. **Сайт.** Загрузите `server/mixer.php` и папку `server/mixer/` в корень сайта. Рядом должна быть папка `data/`, закрытая от веб-доступа (`.htaccess` с `Require all denied`).
2. **Ключ.** Создайте на сервере файл `data/mixer_key.txt` с длинной случайной строкой (не короче 16 символов). Это мастер-ключ **только для программы на ПК**.
3. **ПК.** Запустите `Mixer.exe` (скачайте из Releases или соберите через `windows/build.bat`). В настройках укажите адрес сайта и тот же ключ.
4. **Телефон.** В окне программы: «Ещё» → «Подключить телефон» (покажет QR и код на 5 минут). В приложении Android отсканируйте QR или введите цифры. Телефон получает собственный токен, мастер-ключ он не видит.

## Безопасность

- Мастер-ключ нужен только программе на ПК; телефоны ходят по токенам устройств, сервер хранит только их хэши.
- Вкладка «Ещё» → «Подключённые устройства»: список телефонов, «Отключить» для любого и «Отключить все остальные». Потерялся телефон: отключите его оттуда.
- Токен, которым не пользовались 180 дней, перестаёт работать. Активные продлеваются сами.
- Ввод кода сопряжения ограничен: 5 неверных попыток за 10 минут с одного адреса, код одноразовый.

## Выпуск версий

Вкладка Actions → **Release** → Run workflow. Нужны секреты репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` (подпись APK). Создаётся релиз `v{100 + номер запуска}` с `Mixer.apk` и `Mixer.exe`; приложения сами предлагают обновиться.

## Проверки

```
php -l server/mixer.php
python windows/tests/check_ui.py      # нужен node
python windows/tests/test_e2e.py      # нужен php; Windows не нужен
```

`test_e2e.py` поднимает настоящий `mixer.php`, агент на фейковом звуке и «телефон»: сопряжение, громкость, пресеты, расписания, устройства, задержка команд. Те же проверки идут в CI на каждый коммит.
